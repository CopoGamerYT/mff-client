# MFF Client

MFF Client es un launcher de Minecraft personal, desarrollado por **CopoGamerYT** para **MFF Studios**, este launcher **eventos privados de Minecraft**. Es un proyecto sin ánimo de lucro, hecho con fines de aprendizaje y uso interno.

## ⚠️ Aviso importante

**Este proyecto no está afiliado, respaldado ni asociado de ninguna forma con Mojang Studios o Microsoft.** "Minecraft" es una marca registrada de Mojang Studios/Microsoft. MFF Client es un software independiente creado por un tercero.

## Sobre el modo offline

El modo offline está limitado al contexto de los eventos privados de MFF Studios y a pruebas de desarrollo local. **No otorga acceso a contenido de pago, no desbloquea Minecraft, no genera ni distribuye copias del juego, y no evade ningún sistema de licencias de Mojang/Microsoft.** Este launcher no incluye, enlaza ni promueve ninguna forma de obtener Minecraft de manera no autorizada. Para jugar en línea en servidores con verificación (multijugador oficial, Realms, etc.) es necesario iniciar sesión con una cuenta de Microsoft que posea una licencia legítima del juego, igual que en el launcher oficial.

## Estado del proyecto

En desarrollo activo por una sola persona, como proyecto de aprendizaje. El código todavía tiene mucho margen de mejora (¡sean pacientes con el spaghetti code!). No está pensado para distribución pública ni uso masivo, solo para el círculo de MFF Studios.
